Featured · Personal project

CricClash

A free browser cricket simulation game, built end to end as the sole developer. Players pick a mode, build a side and watch a rules-based engine play out the match.

  • React front end on Cloudflare Pages with a custom domain, backed by a custom rules-based simulation engine written in vanilla JavaScript. The engine is rules-based, not machine learning.
  • Real-time Versus multiplayer over WebSockets on Cloudflare Workers and Durable Objects.
  • Modes include Solo, Versus, Expert vs AI, Elite Pitch, Auction Trilogy and an IPL (T20) mode with 40 real team-seasons and 600 real players built from researched season stats.
  • A Man of the Match algorithm that replicates real-world panel bias, calibrated on 120 matches.
  • Every rating traces to a real researched season stat, and server-only datasets stay off the client.
  • Built with an AI-assisted workflow: Claude researches, diagnoses and drafts prompts, Cursor implements, and I validate the result. AI-built UI changes passed tests, yet I found a bowler exceeding the legal overs limit in T20 only by playing real scenarios.
